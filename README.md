# HIGHWAY RUSH

Mobile-first browser driving game prototype with modular HTML, CSS and JavaScript.

## Structure
- `index.html` — app shell
- `css/main.css` — styles, animations, responsive layout
- `js/main.js` — screens, garage, loader and effects
- `js/audio.js` — music controller
- `assets/audio/phonk.mp3` — upload the soundtrack here
- `assets/models/README.md` — 3D model credits

Serve with a static web server or deploy on Vercel. ES modules require HTTP/HTTPS.

The garage uses interactive 3D viewers for the Nissan GT-R R35 and 2024 Ford Mustang GT. Models load on demand, not during initial page load.
